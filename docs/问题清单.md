## 工作流程约定

1. **修复后必审查**：每修复一个问题、改完代码后，必须自动审查一遍该修复，直到问题彻底修复且不会带来其他问题为止
2. **审查维度**：边界情况、竞态条件、错误处理（失败路径）、副作用（是否引入新问题）、相关调用方受影响情况
3. **清单同步**：修改代码后同步更新本清单（状态标记 + 修复记录）；发现清单外新问题则追加
4. **会话提醒**：新会话开始时若忘记本清单，提醒"先读 docs/问题清单.md"
