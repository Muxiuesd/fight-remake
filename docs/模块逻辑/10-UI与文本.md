# 10 UI 与文本

> 覆盖：`GUISystem`、`UIScreen`/`UIPanel`/`UIComponent`、槽位体系、`TooltipUI`、`Text`/`TextUtil`/`FI18N`/`Fonts`。
> 一句话职责：**用一套“延迟增删 + 递归命中”的组件树画 HUD 与菜单，并把“鼠标是否悬停在 UI 上”告诉世界层，避免点 UI 的同时挖方块**。

## 1. 两条入口

| 入口 | 谁驱动 | 做什么 |
|---|---|---|
| `GUISystem.update(delta)` | 全局系统（世界之前） | `curScreen.update`：刷新 `mouseOver`、处理点击/拖拽、执行延迟增删 |
| `GUISystem.draw()` | GUI 渲染处理器（优先级 10000） | `curScreen.draw`：画组件 |

**update 早于世界更新**，所以 `mouseOverUI()` 对本帧的 `PlayerSystem`/`WorldInputHandleSystem` 是新鲜值。

## 3. 每帧更新链（`UIScreen.update`）

```
UIScreen.update(delta)                              [UIScreen.java:79-213]
 ├─ handleDelayEvents()                             ← 增删队列（遍历安全）
 ├─ setMouseOver(false)                             ← 每帧先清
 ├─ for 顶级组件: component.update(delta)
 │    └─ UIPanel.update 递归子组件
 ├─ 交互判定（仅当未 disabled、可见、且鼠标在屏幕内）：
 │    ├─ 矩形命中 → setMouseOver(true) + component.mouseOver(grid)
 │    ├─ 左键按下 → setClicked + click(grid)
 │    ├─ 左键拖动 → 拖拽逻辑
 │    ├─ 右键 → click(grid)（部分组件用右键）
 │    └─ 移出 → mouseDown(false)
 └─ 清 rectangle（对象池）
```

**`mouseOver` 的写/清/读**：

| 动作 | 位置 |
|---|---|
| 写 true | `UIScreen.java:131`、`UIPanel.mouseOver:220` |
| 清 false | `UIScreen.java:84`、`:101`、`:170`，`UIPanel:199`、`:236-243`（面板 false 级联清子组件） |
| 读 | `GUISystem.mouseOverUI():67-69` → `PlayerSystem:201`、`WorldInputHandleSystem:115` |

## 4. 槽位与物品拖拽

```
PlayerSlotUI.click(grid)
 ├─ 鼠标槽为空 → 从这里拿起（整摞/右键拿一半）
 ├─ 鼠标槽有物品 → 放下/合并/交换（同物品合并到 maxCount）
 └─ 每次点击后 backpack.clear() 清理 amount==0 的脏堆叠
```

| 槽 | 取数来源 |
|---|---|
| `PlayerSlotUI` | `player.getBackpack()` |
| `HotbarPlayerSlotUI` | 背包前 9 格（快捷栏） |
| `EquipmentPlayerSlotUI` | `player.getEquipmentBackpack()` |
| `MouseSlotUI` | 自有 `itemStack` 字段（不碰玩家），单例、`setEnabled(false)` 常驻 |

**关界面自动丢出**：`PlayerUIScreen.hide` 把鼠标槽里的物品 `dropItemIfActiveOn`，避免“关背包后物品消失”。

## 5. 文本与 i18n

```
Text.ofText(key) / ofItem(item) / ofEffect(effect)   ← 拼 "text."/"item."/"effect." 前缀
 └─ getString(langPack, args)
     ├─ 从 LangPack 取模板（缺 key 回退显示 key 本身，不崩）
     └─ 逐个 "{i}" 替换 args（args[i] == null 时填字面量 "NULL"）
 └─ TextUtil.draw：扫 "&&x" 颜色标记，逐段 setColor + draw
```

字体：`Fonts` 按字号给 `BitmapFont`；`UITextButton` 额外 `FONT_SCALE` 缩放并复位；`TextUI` 不缩放（导致槽位数量文字偏大，`F-C12`）。

## 7. 刻意设计与代价

- **延迟增删**：遍历中增删组件安全；移除时顺带清焦点/拖拽/待确认点击。代价：新增组件当帧不可见（下一帧才生效）。
- **`mouseOver` 每帧重置**：不需要“移出事件”，保证状态永远新鲜。代价：任何“漏写 true”的组件都会让世界层收到错误信号。
- **槽位复用一套拿/放/合并/交换逻辑**：行为一致。代价：`MouseSlotUI` 忘了覆写 `getPlayerSystem` 就会 NPE（`H24`）。

## 9. 改动指引

- 新增界面：继承 `UIScreen`（或 `FightUIScreen`），在 `show/hide` 里成对 `addComponent/removeComponent`；`hide` 里处理鼠标槽物品。
- 新增可点击组件：注意 `click` 返回 false 会**终止**同级后续组件的点击分发（`UIPanel.click` 的 break 语义）。
- 新增文本：用 `Text.ofText/ofItem`，不要手拼 key；颜色标记用 `&&x`。
